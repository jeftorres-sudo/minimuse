Free keys

MiniMuse uses two free services. Your keys stay on this device.

How to get it
  1. Make a free account at huggingface.co.
  2. Open Settings → Access tokens.
  3. Create token → type Read → name it MiniMuse → copy it here.
How to get it
  1. Go to aistudio.google.com/apikey and sign in with Google.
  2. Create API key → copy it here. Don't add billing, it stays free.

Free limits

Painting uses Hugging Face's free daily GPU time, enough for a handful of designs a day. If you hit the limit, MiniMuse tells you when to try again.
